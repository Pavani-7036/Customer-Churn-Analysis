# Telecom Customer Churn Analysis | Power BI

## Project Overview
This project focuses on analyzing customer churn in the telecom industry using Microsoft Power BI. The objective is to understand customer behavior, identify churn patterns, and provide insights that can help businesses improve customer retention.

This project was developed as a team project by **Pavani Jambuluri and B. Sadhana**.

## Project Objectives
- Analyze customer churn and retention rates.
- Understand the impact of contract types on customer churn.
- Identify customer segments with higher churn rates.
- Analyze customer demographics, tenure, and service preferences.
- Provide insights to support customer retention strategies.

## Key Insights
- Total Customers: 7,043
- Customer Churn Rate: 26.54%
- Customer Retention Rate: 73.46%
- Month-to-Month Contract Churn Rate: 42.7%
- Two-Year Contract Churn Rate: 2.8%
- Customers with shorter tenure showed higher churn tendencies.

## Tools & Technologies

## Dashboard Analysis
The Power BI dashboard covers:
